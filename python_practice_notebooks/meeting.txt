Test Case Discussion Meeting – Mobile Banking Application
Date: 29 October 2026
Attendees: QA Lead, Test Engineers, Developers, Product Owner

1. The meeting started with a review of the current regression testing progress.
2. The team discussed the test cases planned for the upcoming release.
3. A total of 250 test cases are currently available for the mobile banking application.
4. Out of these, 180 test cases have been automated.
5. The remaining 70 test cases are executed manually.
6. The login module contains 45 test cases covering positive and negative scenarios.
7. The team identified missing test cases for login attempts with locked accounts.
8. Priya Sharma, the QA Lead, requested additional coverage for invalid passwords and expired sessions.
9. The fund transfer module contains 60 test cases.
10. The team agreed that fund transfer is a high-priority business function.
11. All successful fund transfer scenarios must be included in the P1 regression suite.
12. Negative scenarios involving insufficient balances must also be tested.
13. Amit Verma reported a defect where duplicate transfers occurred after repeated button clicks.
14. The development team is investigating the duplicate transfer issue.
15. The defect has been classified as Severity 1 because it may result in financial loss.
16. Amit Verma will provide an update on the defect by 31 October 2026.
17. The account statement module contains 35 test cases.
18. The team noticed that date range validation is not adequately covered.
19. Priya Sharma will ensure new test cases are added for invalid start and end dates.
20. The transaction history should display accurate dates and transaction amounts.
21. The profile management module contains 25 test cases.
22. Rahul Mehta, the Product Owner, discussed testing updates to email addresses and mobile numbers.
23. OTP verification must be validated for both successful and unsuccessful attempts.
24. Neha Kapoor confirmed that the OTP service has undergone recent changes.
25. Neha Kapoor will coordinate additional integration testing for the OTP service.
26. The notification module contains 20 test cases.
27. Push notification testing is currently performed manually.
28. Vikram Singh will evaluate whether notification scenarios can be automated.
29. The payment gateway integration has intermittent failures in the test environment.
30. Neha Kapoor will investigate the environment instability by 1 November 2026.
31. The regression suite currently takes approximately four hours to execute.
32. Priya Sharma proposed reducing the regression execution time to two hours.
33. Vikram Singh will identify redundant test cases and prepare a regression optimization proposal by 3 November 2026.
34. Critical business scenarios will not be removed during test case optimization.
35. Test cases will be categorized into P1, P2, and P3 priorities.
36. P1 test cases will cover critical functionality and major business risks.
37. P2 test cases will cover important workflows and common negative scenarios.
38. P3 test cases will cover low-risk scenarios and less frequently used functionality.
39. Priya Sharma will review test case duplication before approving the removal of any scenarios.
40. Vikram Singh will review the automation scripts before the next regression execution.
41. Priya Sharma requested updated test execution reports for every module.
42. Failed test cases must include screenshots, logs, and clear failure descriptions where applicable.
43. Amit Verma will provide estimated resolution dates for all open critical defects.
44. Rahul Mehta will confirm the final scope of the upcoming release by 2 November 2026.
45. Priya Sharma will complete the test case review by 2 November 2026.
46. Amit Verma will provide an update on the duplicate transfer defect by 31 October 2026.
47. Neha Kapoor will investigate payment gateway instability by 1 November 2026.
48. Vikram Singh will submit the regression optimization proposal by 3 November 2026.
49. Priya Sharma will schedule a follow-up meeting to review progress and outstanding issues.
50. The meeting concluded with agreement on the action items, owners, and deadlines.
